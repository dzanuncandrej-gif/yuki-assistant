# Виртуальный консультант компании

Цифровой ниндзя на сайте: отвечает голосом и текстом на вопросы о компании,
опираясь только на загруженные материалы.

## Что нужно

- **Windows 10/11**
- **Python 3.11+** — https://python.org/downloads (при установке отметить «Add Python to PATH»)
- **Ollama** — https://ollama.com/download
- **Видеокарта с 6 ГБ памяти и больше.** Без неё модель пойдёт на процессоре и
  будет отвечать не за секунду, а за десятки секунд.
- Около 6 ГБ на диске под модели

## Запуск

1. Установить Ollama и запустить его (значок появится в трее).

2. Один раз скачать модели — примерно 5.4 ГБ:

   ```
   ollama pull qwen2.5:7b
   ollama pull bge-m3
   ```

3. Запустить `web\start.bat` двойным щелчком.

   Первый запуск сам создаст окружение и поставит зависимости — это займёт
   пару минут. Дальше запускается сразу.

4. Откроется http://127.0.0.1:8770 — самурай стоит справа внизу, щёлкните по нему.

Прогрев после старта занимает около минуты: поднимаются модели и заранее
считаются ответы на подсказки. До конца прогрева первый ответ будет медленнее.

## Что попробовать

| Вопрос | Что показывает |
|---|---|
| Как дела? | характер ниндзя, ответ мгновенный |
| Сколько стоит ваша работа? | ответ строго по материалам компании |
| скока стоит / `crjkmrj cnjbn` | понимает опечатки, сленг и не ту раскладку |
| Я директор завода, стоит ли с вами работать? | развёрнутый ответ по сути |
| Какая завтра погода? | вежливо отказывается — это не его тема |

Прокрутите страницу по разделам, не открывая окно: реплика самурая меняется под
тот раздел, который вы читаете.

## Своя база знаний

Материалы лежат в `data\docs\`. Поддерживаются PDF, Word, PowerPoint, Excel,
текст и разметка. После замены файлов пересобрать базу:

```
.venv\Scripts\python.exe -c "import sys; sys.path.insert(0,'.'); from core import knowledge, config; from pathlib import Path; knowledge.build('dubrava', [Path('data/docs')], config.load()['brain']['ollama_url'], on_progress=lambda d,w: print(f'{d*100:.0f}% {w}'))"
```

Замени `dubrava` на своё имя базы — так же назови файл персонажа. Персонаж —
его имя, голос, приветствие и подсказки — настраивается в
`data\characters\<имя>.json` (пример: `data\characters\default.json`).

## Если что-то не так

**«Ollama не отвечает»** — не запущен Ollama. Найдите его в меню «Пуск».

**Голос молчит, текст есть** — синтез идёт через сеть, нужен интернет. Ещё
браузер не даёт звук до первого щелчка по странице — щёлкните где-нибудь.

**Отвечает медленно (больше 5 секунд)** — модель считает на процессоре, а не на
видеокарте. Проверить: `nvidia-smi` во время ответа должен показывать
загруженные модели.

**Порт занят** — уже запущен другой экземпляр. Закройте лишнее окно консоли или
смените порт: `python -m web.server --character dubrava --port 8771`.

## Важно про публикацию

Это сборка **без единого инструмента управления компьютером** — она умеет только
отвечать по документам. Настольный ассистент из того же проекта умеет открывать
программы и печатать; выкладывать в интернет можно только эту, веб-часть.

Для настоящего сайта локальная Ollama не годится: одна видеокарта не обслужит
поток посетителей. Там нужен облачный доступ к языковой модели — переключается
адресом в `config.json`.
