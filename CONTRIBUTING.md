# Как участвовать

## Быстрый старт

```powershell
git clone https://github.com/dzanuncandrej-gif/yuki-assistant.git
cd yuki-assistant
powershell -ExecutionPolicy Bypass -File install.ps1
.venv\Scripts\python.exe -m pip install pytest ruff
```

Перед отправкой изменений:

```powershell
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m pytest -q
```

Оба должны быть зелёными — ровно это же гоняет CI.

## Что важно в этом коде

- **Комментарий объясняет «почему», а не «что».** В проекте много мест, где
  очевидное решение уже пробовали и оно не сработало: это записано в комментариях
  рядом. Если меняете такое место — прочитайте объяснение и, если оно перестало
  быть верным, замените его новым, а не удаляйте молча.
- **Инструмент возвращает строку — значит, действие выполнено.** Проверяйте
  результат по-настоящему: появилось ли окно, есть ли файл на диске, опустело ли
  поле ввода. Отчёт без проверки — худшее, что может сделать помощник.
- **Необратимое требует подтверждения.** Новый инструмент, который что-то удаляет,
  перезаписывает, отправляет или запускает чужой код, объявляется с `confirm=True`.
  На это есть тест (`tests/test_security.py`), он упадёт, если флаг забыли.
- **Русский язык интерфейса и ответов — не строки в коде наугад.** Новые надписи
  добавляются через `core/i18n.py`, иначе английский режим их потеряет.

## Тесты

Тесты проверяют чистую логику: разбор речи, сопоставление имён, шаблоны команд,
переводы, флаги безопасности. Они не трогают микрофон, окна и сеть — поэтому
идут за полсекунды и работают в CI.

Нашли баг — начните с теста, который его воспроизводит. В `tests/test_lexicon.py`
и `tests/test_commands.py` уже закреплены реальные поломки: «найди» превращалось
в «юнити», «следующая музыка» не совпадала ни с одним шаблоном. Так они не
вернутся.

## Стиль

- Python 3.12, длина строки до 110.
- Проверка — `ruff` с настройками из `pyproject.toml`; правила про стиль намеренно
  ослаблены, про ошибки — нет.
- Имена и комментарии на русском, если рядом уже русские; код — обычный Python
  без «умных» однострочников.

## Ветки и коммиты

- Ветка от `master`: `fix/что-чиним`, `feat/что-добавляем`.
- Коммит: `тип: суть` (`fix:`, `feat:`, `docs:`, `security:`, `chore:`), тело —
  зачем, а не что.
- Один PR — одна тема. Смешивать рефакторинг с новой функцией не нужно.
