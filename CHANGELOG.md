## [2.0.0] — 2026-10-02

Агент-программист, работа с текстом в любой программе, свой плейлист, сообщения
и большая проверка безопасности перед публикацией.

### Добавлено
- **Агент-программист** (вкладка «Агент», голосом «напиши игру змейка»): план →
  код по файлам (логика → тесты → окно) → unittest → робот, который скрыто нажимает
  все кнопки окна tkinter или страницы сайта → точечные правки по строке ошибки →
  ревью «всё ли из плана сделано» → запуск. Доработка голосом: «добавь в змейку уровни».
  Недавние проекты, живой код с подсветкой, терминал проверок.
- **Действия с выделенным текстом в любой программе:** «переведи это», «перепиши
  вежливее», «исправь ошибки», «сократи», «объясни»; «замени» ставит результат на место.
- **Командная строка `Ctrl+Alt+Пробел`** поверх всех окон с подсказками.
- **Свой плейлист:** встроенный проигрыватель, обложки и теги из файлов, спектр,
  повтор, лайки, поиск, перетаскивание; «включи мою музыку». Музыка тише, пока Юки говорит.
- **«Что мне писали?»** — пересказ новых сообщений Telegram без открытия чатов.
- **«Что мне ему ответить?»** — три варианта ответа в открытом чате, «вставь»/«отправь».
- **«Доброе утро»** — погода, напоминания, сообщения и новости одним рассказом.
- **«Что за ошибка?»** — разбор ошибки в коде на экране, исправление в буфере обмена.
- **Вкладка «Память»:** что Юки знает о тебе, добавить и удалить.
- **Книга людей** для сообщений: «Дима» → «Дмитрий Иванов».
- Обучение при первом запуске, голосом: проверка системы, выбор голоса, уроки.
- Журнал `data/yuki.log` и замер скорости `scripts/benchmark.py`.

### Быстрее
- Первый ответ после запуска: 5,6 с → 0,4 с (прогрев грузил модель с другим контекстом).
- Вопросы про экран больше не перезагружают модель (одинаковый `num_ctx` во всех запросах).
- Агент-программист уступает модель разговору: пока ты говоришь, он ждёт.
- Одна модель `qwen3.5:9b` думает, видит экран и вызывает инструменты.

### Надёжнее
- Упавшая Ollama поднимается сама, запрос повторяется.
- Если устройство звука перестало принимать звук, голос переходит на работающее.

### Безопасность
- Защита от «внедрённых команд»: после чтения страницы, экрана или файла рискованные
  действия — только по прямой просьбе или после «да».
- «Открой сайт» — только http/https; чтение страниц моделью закрыто для локальной сети.
- Личные данные (люди, память, плейлист, проекты, журналы) исключены из git; материалы
  клиентов убраны из репозитория.

### Установка
- Установщик проверяет место, Python и видеокарту, создаёт `config.json`, предлагает
  Ollama через winget; необязательные шаги не обрывают установку.
- Зависимости: полный PySide6 (веб-движок интерфейса) и onnxruntime.
- Ярлык называется «Юки».

## [1.1.0] — 2026-09-30

Новый интерфейс, возвращённая видеосвязь и развёрнутые ответы.

### Добавлено
- **Окно видеосвязи** (`Ctrl+D`, кнопка в пульте, пункт в трее, голосом «давай созвонимся»):
  ядро из частиц во весь экран, живой кадр экрана и камеры, описание сцены, жесты,
  субтитры, лента разговора. `Esc` — окошко 360×460 поверх окон, второй `Esc` или
  «заверши звонок» — отбой с итогом. Ядро звонка было, окна к нему не было.
- **Командный центр «Диалог»** на WebGL (`ui3d/hub.html`): ядро меняет форму по
  состоянию — сфера, звуковая волна, нейросеть, стена инструментов; переписка с
  шагами агента, развёрнутыми ответами в markdown и копированием кода.
- **Развёрнутые ответы:** «объясни», «сравни», «напиши код», «составь план»,
  «посоветуй» идут в экспертный режим (`brain.deep_think`, рассуждение qwen3).
  Вслух — суть в одну-две фразы, разбор — карточкой на экране.
- **Новый пульт:** шрифты сайта (Unbounded, Inter Tight, JetBrains Mono — OFL,
  `assets/fonts`), навигация с иконками и переезжающей подсветкой, живая карточка
  состояния с мини-ядром, кнопка видеосвязи, плитка раздела, туманность на фоне.
- `restart_as_admin` — перезапуск Юки с правами администратора.

### Зрение
- **Быстрое восприятие экрана без видеокарты:** встроенный OCR Windows
  (`core/ocr.py`, постоянный процесс `ocr_server.ps1`) плюс структура окна.
  Весь экран читается за ~0,2–0,3 с; при каждой смене сцены видно и то, что
  только что появилось.
- **Вопросы про экран отвечает основная модель** по тексту экрана — без
  перезагрузки весов: первое слово через ~0,9 с вместо 5–15 с. Модель зрения
  зовётся только для картинок, видео и игр.
- Ошибки на экране замечаются сразу по тексту, а не раз в десятки секунд.
- `click_control` нажимает надпись по OCR, если в дереве окна её нет;
  `read_screen` и `read_window_text` включают распознанный текст.
- Звонок больше не прогревает модель зрения на старте — она выталкивала
  основную модель из видеопамяти.

### Изменено
- Голоса выбраны на слух на странице прослушки: мужские WILLIAM (основной),
  RÉMY, ДМИТРИЙ; женский ЮКИ — Vivienne Multilingual «живее» (+6 %, +4 Гц).
  Звук без обработки. Старые ключи (`jarvis`, `atlas`, `sora`…) ведут в новые.
- Ядро из частиц легче: меньше частиц и ниже внутреннее разрешение, 60 к/с. Замер
  чередованием: с ядром на 60 к/с модель выдаёт 58–59 токенов/с, без него 58–63.
- Экспертный режим без рассуждения по умолчанию (`brain.deep_think`).
- Меню: инерционная прокрутка, мягкие переходы разделов, плавные наведения.

### Исправлено
- Нейроголос ждал сеть без предела и при обрыве менял голос посреди ответа:
  теперь таймаут, повтор, упреждающий синтез и быстрый переход на офлайн.
- Окна, запущенные от администратора, молча выбрасывали ввод Юки (UIPI), а она
  докладывала «нажала». Теперь она видит это заранее и говорит, в чём дело.
- Зависший звуковой драйвер Windows вешал весь запуск: окно не появлялось. Выбор
  микрофона теперь ограничен по времени, текстом Юки работает и без звука.

## [1.0.0] — 2026-09-22

Первый публичный выпуск, приведённый в порядок: безопасность, тесты, CI.

### Добавлено
- Тесты (`pytest`, 81 проверка): разбор речи, сопоставление имён адресатов,
  шаблоны команд, переводы интерфейса, флаги безопасности инструментов.
- CI на GitHub Actions: линтер и компиляция на Ubuntu, тесты на Windows,
  проверка `config.example.json` на личные данные.
- `files.restrict_paths` — файловые инструменты запираются в домашней папке
  (тумблер в меню → Аккаунт).
- `tts.allow_cloud_voice` — сетевой синтез Edge только по явному разрешению.
- Английский интерфейс целиком (`core/i18n.py`) плюс переключение языка речи
  командой «switch to english» / «говори по-английски».
- `requirements.lock.txt` — точные версии для воспроизводимой установки.
- `SECURITY.md`, `CONTRIBUTING.md`, `pyproject.toml`, шаблоны issue и PR.

### Безопасность
- `run_shell` и `write_file` требуют подтверждения голосом — как `delete_path`
  и `power_control`.
- WebSocket браузерного режима проверяет заголовок `Origin`: чужая вкладка
  больше не подключится.
- Edge-TTS не подменяет локальный синтез молча — текст ответа не уходит в сеть
  без ведома пользователя.
- Полный traceback ошибки инструмента пишется в `data/errors.log` (локально,
  в `.gitignore`).

### Исправлено
- Словарь исправлений портил слова: «найди» превращалось в «юнити» (имя
  установленной программы), «дела» — в «сделай», «устал» — в «удали». Заодно
  молча ломались команды «найди видео», «найди картинку».
- «Следующая музыка» не совпадала ни с одним шаблоном — в списке слов после
  «следующая/дальше» не было самой «музыки».
- Модель зацикливалась на одной удачной подколке и повторяла её весь разговор.
- Персонаж переходил от дружеских подколок к настоящей грубости.
- Установщик тянул модель зрения `llava`, хотя код предпочитает и документирует
  `qwen2.5vl:3b` (llava заметно хуже понимает русский).
- Дубликаты ключа `"юки"` в словаре псевдонимов голосов — смысл зависел от
  того, какая строка последняя.
- Замыкания в веб-серверах захватывали переменные цикла вместо своих значений.
- README обещал «всё работает локально», умалчивая про сетевой Edge-TTS;
  инструментов было 88, а заявлено 58; иконка называлась `jarvis.ico`, хотя
  файл — `yuki.ico`.

### Убрано
- Из репозитория исключены 3D-модели и рисованный референс компаньона
  (права на них неясны), данные и документы стороннего клиента, личный
  `config.json`. Приложение работает без них: компаньон рисуется встроенным
  векторным риггом, свою модель каждый подставляет сам.
