# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-22

Первый публичный выпуск, приведённый в порядок: безопасность, тесты, CI.

### Добавлено
- Тесты (`pytest`, 81 проверка): разбор речи, сопоставление имён адресатов,
  шаблоны команд, переводы интерфейса, флаги безопасности инструментов.
- CI на GitHub Actions: линтер и компиляция на Ubuntu, тесты на Windows,
  проверка `config.example.json` на личные данные.
- `files.restrict_paths` — файловые инструменты запираются в домашней папке
  (тумблер в меню → Аккаунт).
- `tts.allow_cloud_voice` — сетевой синтез Edge только по явному разрешению.
- Английский интерфейс целиком (`core/i18n.py`) плюс переключение языка речи
  командой «switch to english» / «говори по-английски».
- `requirements.lock.txt` — точные версии для воспроизводимой установки.
- `SECURITY.md`, `CONTRIBUTING.md`, `pyproject.toml`, шаблоны issue и PR.

### Безопасность
- `run_shell` и `write_file` требуют подтверждения голосом — как `delete_path`
  и `power_control`.
- WebSocket браузерного режима проверяет заголовок `Origin`: чужая вкладка
  больше не подключится.
- Edge-TTS не подменяет локальный синтез молча — текст ответа не уходит в сеть
  без ведома пользователя.
- Полный traceback ошибки инструмента пишется в `data/errors.log` (локально,
  в `.gitignore`).

### Исправлено
- Словарь исправлений портил слова: «найди» превращалось в «юнити» (имя
  установленной программы), «дела» — в «сделай», «устал» — в «удали». Заодно
  молча ломались команды «найди видео», «найди картинку».
- «Следующая музыка» не совпадала ни с одним шаблоном — в списке слов после
  «следующая/дальше» не было самой «музыки».
- Модель зацикливалась на одной удачной подколке и повторяла её весь разговор.
- Персонаж переходил от дружеских подколок к настоящей грубости.
- Установщик тянул модель зрения `llava`, хотя код предпочитает и документирует
  `qwen2.5vl:3b` (llava заметно хуже понимает русский).
- Дубликаты ключа `"юки"` в словаре псевдонимов голосов — смысл зависел от
  того, какая строка последняя.
- Замыкания в веб-серверах захватывали переменные цикла вместо своих значений.
- README обещал «всё работает локально», умалчивая про сетевой Edge-TTS;
  инструментов было 88, а заявлено 58; иконка называлась `jarvis.ico`, хотя
  файл — `yuki.ico`.

### Убрано
- Из репозитория исключены 3D-модели и рисованный референс компаньона
  (права на них неясны), данные и документы стороннего клиента, личный
  `config.json`. Приложение работает без них: компаньон рисуется встроенным
  векторным риггом, свою модель каждый подставляет сам.
