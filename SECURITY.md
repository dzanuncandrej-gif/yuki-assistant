# Безопасность

## Что это за программа с точки зрения рисков

Юки — не изолированное приложение, а агент с правами вашего пользователя Windows:
файлы, клавиатура, мышь, оболочка, мессенджеры, экран, камера. Языковая модель,
которая им управляет, ошибается — и этого достаточно, чтобы навредить, даже без
злого умысла.

Поэтому главное правило: **не ставьте Юки на компьютер с доступом к рабочей почте,
CRM, банковским кабинетам и чужим документам.**

## Что уже защищено

| Риск | Что сделано |
|---|---|
| Выполнение произвольных команд | `run_shell` требует подтверждения голосом + чёрный список разрушительных шаблонов |
| Перезапись и удаление файлов | `write_file`, `delete_path` требуют подтверждения; перезапись обратима через журнал |
| Выход за пределы своих файлов | `files.restrict_paths` запирает инструменты в домашней папке |
| Необратимые действия с системой | `power_control`, `empty_recycle_bin` требуют подтверждения |
| Чужая веб-страница в браузерном режиме | WebSocket проверяет `Origin`, сервер слушает только `127.0.0.1` |
| Утечка текста ответа в сеть | Edge-TTS включается только явно (`engine: "edge"`, английский режим или `tts.allow_cloud_voice`) |
| Секреты в репозитории | `config.json` и `.env` в `.gitignore`, значения вида `${КЛЮЧ}` берутся из окружения |

## Что ещё открыто

Это честный список, а не оправдание — он же в README:

- `run_shell` не песочница: у него чёрный список, а не белый.
- Нет токена доступа к WebSocket: локальная программа на том же компьютере может
  подключиться, если браузерный режим запущен.
- `confirm_contact` доверяет модели: инструмент ставит отметку «человек согласился»,
  но не проверяет, что согласие действительно прозвучало.
- Зависимости не проверяются по хэшу. Для воспроизводимой установки есть
  `requirements.lock.txt`, но не sha256-пиннинг.
- Модель Silero загружается через `torch.package`/`load_pickle` — формат, способный
  исполнить код. Скачивайте модели только по ссылкам из этого репозитория.

## Рекомендуемая настройка для осторожных

```jsonc
{
  "files": { "restrict_paths": true },     // не выходить за домашнюю папку
  "tts":   { "allow_cloud_voice": false }, // никакой сети в синтезе
  "server":{ "host": "127.0.0.1" },        // браузерный режим только локально
  "camera":{ "enabled": false }            // если камера не нужна
}
```

И не запускайте `start.ps1 -Admin`, пока действительно не потребуются права
администратора: с ними последствия любой ошибки модели больше.

## Как сообщить об уязвимости

Откройте issue с пометкой `security` в
[репозитории](https://github.com/dzanuncandrej-gif/yuki-assistant/issues) — или,
если считаете находку опасной для пользователей, напишите о ней без публичных
подробностей и дождитесь ответа. Проект личный, гарантированного времени реакции
нет, но замечания по безопасности разбираются первыми.
